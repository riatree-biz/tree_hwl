# 업무 통합 관리 시스템

## 실행
1. 압축을 푼 폴더에서 터미널을 엽니다.
2. `python -m http.server 8000` 실행
3. 브라우저에서 `http://localhost:8000` 접속

또는 VS Code Live Server로 `index.html`을 실행합니다.

## 주요 기능
- 대시보드: 문의 및 개발·배포 전체 건수, 미완료 건수
- 문의 관리: 병원/문의자/문의내용/처리내용/문의일자/처리일자/완료여부 등록·수정·삭제·검색·필터
- 개발·배포 관리: 기존 항목과 탭/검색/병원·구분 필터/CSV 내보내기/배포완료 처리
- 공통 저장: 변경 시 브라우저 localStorage에 저장
- JSON 저장: `data.json 저장`으로 JSON 다운로드 또는 Chrome/Edge에서 저장 파일 연결
- HTML 저장: 현재 화면을 `YYYY-MM-DD.html`로 저장

## 데이터 저장 관련 참고
정적 HTML은 서버의 `data.json`을 직접 덮어쓸 권한이 없습니다. 따라서 브라우저 저장소를 기본 저장소로 사용하고, JSON 저장 버튼으로 파일에 내보냅니다. Chrome/Edge에서 localhost로 실행하면 파일 선택 API를 통해 `data.json`을 연결하여 이후 저장 시 해당 파일을 갱신할 수 있습니다.

기존 `data.json`의 배열 형식은 최초 로드 시 `deployments` 배열로 자동 변환됩니다. 배포 패키지의 `data.json`에는 제공된 원본 개발·배포 예시 2건이 유지되어 있습니다.
