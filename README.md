# 업무 통합 관리 시스템

## 화면 구성
- `index.html` : 업무 대시보드(화면별 건수, 완료율 도넛 차트, 데이터 분포, 최근 변경 타임스탬프)
- `inquiry.html` : 병원 문의 등록·수정·삭제·검색
- `deploy.html` : 개발·배포 작업 등록·수정·삭제·검색
- `SaveDataRequest.html` : 병원 사용자의 데이터 처리 요청 접수·진행·완료 관리
- `SaveSetting.html` : 화면별 JSON 파일 연결·불러오기·저장·연결 해제

## 데이터 파일
- `inquiries.json` : 문의 데이터
- `deployments.json` : 개발·배포 데이터
- `dataRequests.json` : 병원 데이터 처리 요청
- `data.json` : 이전 데이터 마이그레이션 참고용

## 실행
압축 해제 후 프로젝트 폴더에서 아래 명령을 실행하고 `http://localhost:8000`으로 접속합니다.

```bash
python -m http.server 8000
```

VS Code Live Server로 실행해도 됩니다.

## JSON 파일 관리
`SaveSetting.html`에서 각 데이터 파일을 연결하고 읽기·쓰기 권한을 허용하면 해당 업무 데이터의 등록·수정·삭제 시 연결된 파일에 자동 저장됩니다. Chrome 또는 Edge의 localhost 환경에서 File System Access API를 지원합니다. 그 외 브라우저에서는 브라우저 저장소와 JSON 파일 불러오기·다운로드 방식으로 동작하며 기존 파일을 자동으로 덮어쓰지 않습니다.

`SaveDataRequest.html`은 병원 사용자의 데이터 처리 요청 업무 전용 화면입니다. 접수번호, 병원명, 요청자, 요청 유형, 요청 상세, 접수일, 처리 담당자, 상태, 완료일, 처리 결과 및 생성·수정 타임스탬프를 기록합니다.


## 체크리스트 및 이미지 보관함
- `SaveCheckList.html`에서 체크 항목의 시작일, 종료일, 반영일과 개발기·스테이징·운영기 반영 여부를 CRUD로 관리합니다.
- 체크리스트 데이터는 `checklists.json`으로 분리되어 JSON 설정 화면에서 연결·불러오기·저장할 수 있습니다.
- 모든 화면 하단의 이미지 보관함에서 이미지 업로드, 미리보기, 삭제를 지원합니다. 이미지는 브라우저 localStorage에 저장되며 JSON 파일에는 포함되지 않습니다. 이미지 1장당 최대 1.5MB, 전체 보관함 최대 3MB입니다.

### 항목별 이미지 첨부
- 문의, 개발·배포 작업, 병원 데이터 처리 요청, 체크리스트는 각 레코드(행)별로 이미지를 첨부할 수 있습니다.
- 이미지 데이터는 해당 레코드의 `images` 배열에 포함되어 각 업무 JSON 파일에 함께 저장됩니다.
- 이미지당 최대 1.5MB, 레코드당 최대 5장입니다.
- 목록의 첨부 이미지 미리보기를 선택하면 원본 이미지를 새 탭에서 확인할 수 있습니다.

## 입력 모달 사용성 및 코드 가독성
- 등록/수정 팝업은 화면 높이에 맞춰 최대 높이가 제한됩니다.
- 이미지 미리보기 등으로 입력 내용이 길어지면 팝업 전체가 잘리는 대신 본문 영역에서 세로 스크롤할 수 있습니다. 제목과 저장/취소 버튼은 계속 표시됩니다.
- 작은 화면에서도 동일하게 스크롤할 수 있도록 모바일 높이와 여백을 별도로 조정했습니다.
- 체크리스트 화면의 HTML·JavaScript에는 화면 구조, 데이터 흐름, 검증, 이미지 처리 함수의 역할을 주석으로 설명했습니다.

## 오류 수정 및 코드 정리

- `common.js`의 `Store.loadAll()`에서 4종 데이터를 모두 반환하도록 결과 변수 누락을 수정했습니다.
- IndexedDB를 지원하지 않거나 브라우저 저장소 접근이 제한된 경우에도 가능한 범위에서 임시 저장소·파일 다운로드 방식으로 동작하도록 예외 처리를 보강했습니다.
- `index.js`는 데이터 배열과 화면 요소를 확인한 뒤 대시보드를 갱신하고, 비동기 오류가 콘솔에서 추적되도록 정리했습니다.
- 중복된 날짜 필드 참조와 사용하지 않는 변수 등 확인된 불필요 코드를 정리했습니다.
